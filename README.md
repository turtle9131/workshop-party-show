# 🎉 워크샵 파티 쇼: 진행 가이드

폰 하나로 진행하고, 그 화면을 TV나 프로젝터에 미러링하는 팀 대항 파티 게임입니다.

## 준비물
- 진행자 폰 1대: 인터넷 연결 필요 (노래 재생에 사용)
- TV 또는 프로젝터 미러링: 갤럭시는 Smart View, 아이폰은 AirPlay, 또는 크롬캐스트
- 노이즈캔슬링 헤드폰 (고요 속의 외침용, 선택)

## 시작 전 체크 (미러링을 켜기 전에!)
1. 폰에서 게임 주소를 열고 **가로 모드**로 둡니다.
2. 🏠 홈 → **🔊 사운드 준비** → 영상의 ▶를 직접 한 번 누르고 소리가 나는지 확인한 뒤 **완료**를 누릅니다.
3. ⚙️ 설정에서 팀 이름과 벌칙 룰렛 항목을 수정합니다.
4. 무음 모드를 끄고 볼륨을 최대로 올립니다. 화면 자동 꺼짐은 앱이 막아 줍니다.
5. 미러링을 켭니다. 폰 알림이 TV에 뜨지 않도록 **방해금지 모드**를 켜 두세요.

## 📋 운영자 정답지
미러링 중에는 폰 화면이 TV에 그대로 나가므로 **정답은 다른 기기나 종이로** 봅니다.
- 정답지 주소: `answers.html` (배포 주소 뒤에 붙이면 됩니다. 게임의 ⚙️ 설정 → 📋 정답지 열기로도 갈 수 있습니다)
- 문제 순서는 **문제 세트 번호**로 고정됩니다. 게임 설정의 번호와 정답지의 번호가 같으면 "Q 번호"와 정답지 번호가 일치합니다.
- OST(전체/드라마/영화)와 초성(카테고리별)은 고른 필터마다 목록이 따로 있습니다.
- 리허설은 세트 2번으로 하고 본게임은 1번으로 하면, 리허설 때 본 순서가 본게임에 그대로 나오지 않습니다.
- 인쇄 버튼으로 종이 정답지를 뽑을 수 있습니다.

## 추천 진행 순서 (약 2시간)
| 순서 | 게임 | 시간 | 진행 팁 |
|---|---|---|---|
| 0 | 🎲 팀 나누기 | 5분 | **👑 리더 드래프트**: 사전 게임으로 뽑힌 리더 2명이 번갈아 팀원을 뽑습니다. 무작위로 나눌 수도 있습니다. |
| 1 | 🎵 1초 노래 퀴즈 | 15분 | 1초 → 3초 → 5초 순서로 들려주고, 먼저 "정답!" 외친 팀에게 기회를 줍니다. 맞히면 노래가 이어서 나오니 떼창을 유도하세요. |
| 2 | 🎬 OST 퀴즈 | 15분 | 드라마·영화 OST를 듣고 **작품 제목**을 맞힙니다. 위쪽에서 전체/드라마/영화를 고를 수 있습니다. |
| 3 | 🔤 초성 퀴즈 | 15분 | 카테고리(영화, 드라마, 연예인, 음식, 예능, 브랜드, **MZ 용어**)를 골라 진행합니다. MZ 용어는 정답 공개 때 뜻도 함께 나옵니다. 한 글자씩 공개할수록 점수가 내려갑니다 (3 → 2 → 1점). ⏱ 10초 버튼으로 긴장감을 더할 수 있습니다. |
| 4 | 📸 확대 사진 퀴즈 | 15분 | 줌아웃할수록 점수가 내려갑니다 (4 → 3 → 2 → 1점). |
| 4.5 | 📺 다음 장면 맞히기 | 10분 | 영상이 결정적 순간에 멈추면 보기 3개 중 다음 장면을 두 팀이 동시에 맞힙니다(맞히면 +2, 두 팀 다 맞힐 수 있음). |
| 5 | 🎭 몸으로 말해요 | 20분 | 쉬운 한 단어 제시어(동물·스포츠·직업·일상 동작·물건·음식). 맞히는 팀은 TV를 등지고, 설명하는 사람만 TV를 봅니다. |
| 6 | 🕵️ 마피아 / 🤥 라이어 | 20분 | 둘 중 하나를 골라 진행합니다. 사회자가 진행하고 역할·제시어는 각자 폰으로 확인합니다. |
| 7 | 🏆 시상식 · 🎰 벌칙 룰렛 | 10분 | 🏅 점수판 → 🏆 시상식으로 팀·개인 시상, 진 팀은 벌칙 룰렛! |

노래·OST·초성·사진 퀴즈는 푼 문제를 기억해서, 다른 게임에 갔다 와도 이어서 진행됩니다. 처음부터 하려면 각 화면의 **↺** 버튼이나 ⚙️ 설정 → 점수 초기화를 누르세요.

점수판(화면 위쪽)의 −/＋ 버튼으로 언제든 점수를 조정할 수 있습니다. 점수는 폰에 저장되어 새로고침해도 유지됩니다.

## 👑 리더 드래프트 · 🏅 개인 점수 · 🏆 시상식
**팀 구성:** 사전 게임으로 리더 2명을 정하고, 리더가 번갈아 팀원을 뽑습니다.
1. 🎲 팀 나누기에 참가자 이름을 넣고 **👑 리더 드래프트**를 누릅니다.
2. 사전 게임에서 이긴 2명을 차례로 누릅니다. 먼저 누른 사람이 A팀 리더입니다. 누가 먼저 뽑을지(A 먼저 / B 먼저 / 🪙 동전 던지기)를 고르고 **▶ 드래프트 시작**을 누릅니다.
3. TV에 "👑 철수 리더 차례"가 뜨면 리더가 고른 사람 이름을 누릅니다. 차례는 자동으로 번갈아 가고, 마지막 1명은 자동으로 배정됩니다. 잘못 눌렀으면 **↩️ 취소**를 누릅니다.
4. 팀 이름은 "철수팀 / 수진팀"처럼 리더 이름으로 바뀝니다. 끄고 싶으면 리더 화면의 🏷 버튼을 누릅니다.

**점수:** 게임은 팀전이고, 문제를 맞힌 사람에게는 개인 포인트를 줍니다.
- 어느 게임에서든 팀 점수가 오르면 화면 아래에 **"누가 맞혔나요?"** 창이 뜹니다. 맞힌 사람 이름을 누르면 개인 포인트(+1/+2/+3)가 들어갑니다.
  - 폰 버저를 쓰면 **먼저 누른 사람이 🔔로 맨 앞에** 나옵니다.
  - 팀 전체가 맞힌 문제는 **👥 팀 전원**, 개인 점수가 필요 없으면 **건너뛰기**를 누릅니다.
- 위쪽 점수판의 **🏅** 버튼(또는 홈의 🏅 점수판)에서 팀 점수와 개인 포인트를 −/＋로 고칠 수 있습니다. "누가 맞혔나요?" 창도 여기서 끌 수 있습니다.

**참가자 폰에서 점수 보기 (노트북 서버 + 📱 폰 연결):**
- 대기 화면에 팀 점수, 내 포인트, 개인 순위가 실시간으로 나옵니다. 게임 중에는 오른쪽 위 **🏅 점수** 버튼으로 봅니다.
- 🏅 점수판에서 공개 범위를 정합니다.
  - **팀 + 개인 순위**
  - **팀 점수만**: 개인 순위는 숨기고 내 포인트만 보입니다. 시상식 전 긴장감용입니다.
  - **숨김**

**🎤 사회자 폰 (정답지 보면서 점수 주기, 노트북 서버 전용):**
1. 진행 화면 홈의 **🎤 사회자 폰**(또는 📱 폰 연결 / 🏅 점수판 안의 버튼)을 누르면 사회자 전용 QR이 뜹니다.
2. **사회자만** 찍고 바로 [✅ 찍었어요 → 닫기]를 누릅니다. TV에 비치므로 참가자들이 잠깐 고개를 돌리게 하세요.
   - 다른 사람이 찍었다면 **🔄 키 바꾸기**를 누르세요. 기존 사회자 폰이 끊기고 새 QR이 나옵니다.
3. **🎮 진행 탭 (기본):** 지금 TV에 떠 있는 게임의 **문제 번호와 정답**이 사회자 폰에만 크게 보이고, 노트북 버튼을 폰에서 대신 누를 수 있습니다.
   - **노래·OST:** 1초/3초/5초/10초 재생, ▶ 계속 듣기, ■ 정지, 💡 힌트, 👀 정답 공개, ◀ 이전, 다음 ▶
   - **초성:** ⏱ 10초, 💡 한 글자 공개, 👀 정답 공개, 다음 ▶
   - **사진:** 🔍 줌 아웃, 👀 정답 공개, ◀ 이전, 다음 ▶
   - **몸으로 말해요:** 팀 차례 고르기, ▶ 시작, ⭕ 정답, ⏭ 패스(지금 제시어도 보임), 점수 반영, 다음 라운드
   - **🎰 벌칙 룰렛:** 돌려!
   - **[A팀 정답 +n]:** 그 단계의 점수가 들어가고 TV에서 정답 공개까지 한 번에 처리됩니다. 누가 맞혔는지 고르면 개인 포인트도 들어갑니다.
4. 사회자 폰 화면 구성 (나머지):
   - **위쪽:** 두 팀 점수와 **+1 / +2 / +3** 버튼이 있습니다. 누르면 "누가 맞혔나요?"가 떠서 맞힌 사람(또는 👥 팀 전원 / 팀 점수만)을 고릅니다. 개인 포인트는 +1/+2/+3 중에서 고릅니다.
   - **− 1점 빼기:** 팀 점수만 1점 뺍니다.
   - **📋 정답지:** 진행 화면의 문제 세트 번호에 맞춰 자동으로 열립니다.
   - **🏅 개인 점수:** 개인 순위를 보고 −/＋로 고칩니다.
   - **↩️ 취소:** 사회자 폰으로 준 점수를 최근 것부터 하나씩 되돌립니다.
5. 누르면 TV 점수판과 참가자 폰에 바로 반영됩니다. 맨 위에 "✅ 진행 화면과 연결됨"이 보여야 합니다.
   - "⚠️ 진행 화면이 꺼져 있어요"가 보이면 노트북 브라우저에서 진행 화면을 다시 여세요.
- 한 번 접속하면 키가 폰에 저장돼서 다음부터는 `http://노트북주소:8000/host.html`만 열어도 됩니다.

**🏆 시상식:** 🏅 점수판 → 🏆 시상식에서 팀 우승 → 개인 3위 → 2위 → 1위(MVP) 순서로 "두구두구" 후 공개합니다.
- 포인트가 같으면 공동 수상입니다.
- 마지막 화면의 **📱 폰에 전체 순위 공개**를 누르면 모두의 폰에 최종 순위가 뜹니다.
- 새 행사를 시작할 때는 ⚙️ 설정 → **점수 초기화**로 팀 점수와 개인 포인트를 함께 지웁니다.

## 📺 다음 장면 맞히기
- **진행:** [▶ 재생]을 누르면 영상이 결정적 순간 직전에 자동으로 멈추고 문제와 보기 ①②③이 뜹니다. ⏱ 10초 뒤 "셋, 둘, 하나"에 두 팀이 동시에 손가락으로 답하고, [👀 정답 공개]를 누르면 뒷장면이 재생됩니다. 맞힌 팀마다 [정답 +2]를 누르세요.
- **기본 영상 8개:** 국내 4개(무한도전 무야호, 김치 싸대기, 무한도전 한강 얼음 위 정형돈, 눈사람 된 박대기 기자)가 먼저 나오고, 외국 4개(재채기 판다, 오이 고양이, 포도 리포터, 수영장 결혼식)가 이어집니다. YouTube 자동 자막은 꺼서 대사가 미리 보이지 않습니다. 멈춤 시간은 화면을 직접 확인해 정답·자막이 보이기 전으로 맞췄습니다.
- **✏️ 영상 추가·관리:** 국내 예능·드라마 장면을 직접 넣을 수 있습니다. YouTube 주소를 붙여넣고 [불러오기] → 영상을 보면서 📍 시작 / 📍 멈춤 / (서서히 변하는 영상이면) 📍 정답 장면 / 📍 끝을 누름 → 문제와 보기 3개, 정답(✅)을 쓰고 [💾 저장]. 멈춤은 **편집 자막이 정답을 말하기 전**으로 잡으세요.
  - 직접 만든 문제는 **그 노트북 브라우저에만** 저장되고 목록 맨 뒤에 붙습니다. 종이 정답지에는 안 나오니 🎤 사회자 폰에서 정답을 보세요.
- 영상 위쪽의 검은 띠는 YouTube 영상 제목(정답이 적혀 있는 경우가 많음)을 가리는 가리개입니다.

## 🎁 상품 · 패배팀 상품 뽑기
| 구분 | 상품 |
|---|---|
| 🏆 우승팀 | 배민 상품권 3만원 × 5 (팀원 모두) |
| 👑 개인 우수상(MVP) | 상품권 10만원 (공동 1위면 사회자가 정함) |
| 패배팀 | 보조배터리 3 · 와인 2 → 상자 5개 랜덤 뽑기 |

- 🏆 시상식 화면에 상품이 함께 표시되고, 마지막 화면의 **🎁 패배팀 상품 뽑기**(또는 홈의 🎁 상품 뽑기)로 이어집니다.
- 점수가 낮은 팀이 자동으로 패배팀으로 잡힙니다(동점이면 버튼으로 고름). 상자 개수는 −/＋로 바꿀 수 있습니다.
- 차례(무작위 순서)인 사람이 상자 번호를 고르면 "두구두구" 뒤에 열립니다. 🎤 사회자 폰에서도 상자를 열 수 있습니다.
- 상자 5개가 모두 선물이라 팀원 5명이면 한 명씩 하나를 받습니다(6명 이상이면 못 받는 사람이 생긴다는 경고가 뜹니다). 잘못 눌렀으면 **↩️ 취소**.

## 🕵️ 마피아 (사회자 진행)
진행 폰은 TV에 나가므로 역할을 띄우지 않고, **참가자가 각자 자기 폰으로** 역할을 확인합니다. 사회자는 게임에 참여하지 않고 진행 폰을 듭니다.
1. **준비:** 참가자 이름(사회자 제외)을 넣고 역할 수를 정합니다. 10명이면 마피아 2, 경찰 1, 의사 1, 시민 6이 기본입니다. 탈락자 직업 공개와 음성 안내를 켜고 끌 수 있습니다.
2. **역할 확인:** 준비 화면에서 방식을 고릅니다. 어느 쪽이든 역할은 화면을 **꾹 누르는 동안만** 보이고, 마피아는 동료 마피아도 함께 보입니다.
   - **📡 노트북 서버:** 노트북에서 서버를 켰을 때만 나타나는 방식입니다. 아래 [📡 노트북 서버](#-노트북-서버-폰으로-참여하기)의 마피아 부분을 보세요.
   - **🔒 한 명씩 개인 QR:** "모두 눈을 감으세요. 철수 님만 눈을 뜨고 QR을 찍으세요" 음성에 맞춰 한 명씩 **자기 전용 QR**을 찍고, 사회자가 [찍었어요 → 다음 사람]을 누릅니다. 개인 QR에는 그 사람의 역할만 들어 있어서 **다른 사람 역할은 볼 수 없습니다.** QR을 못 찍은 사람은 이름을 눌러 개인 링크를 복사해 **그 사람에게만 1:1 톡**으로 보내세요.
   - **⚡ 전체 QR (빠름):** QR 하나를 다 같이 찍고 자기 이름을 누릅니다. 빠르지만 다른 사람 이름을 누르면 그 사람 역할이 보이므로, 시작 전에 "본인 이름만"이라고 꼭 말해 주세요. QR을 못 찍으면 [링크 복사]로 단톡방에 올리세요.
3. **밤:** 앱이 음성으로 "마피아는 눈을 뜨세요…"를 순서대로 안내합니다. 사회자는 지목된 사람을 누르기만 하면 됩니다.
   - 경찰 조사 결과(👍/👎)는 TV에 뜨고, 눈을 뜬 경찰이 직접 봅니다.
   - 의사나 경찰이 이미 죽었으면 아무도 눈을 뜨지 않으니 [아무도 안 뜸 · 넘어가기]를 누르세요.
4. **아침:** 밤 결과가 발표됩니다 (누가 당했는지, 의사가 살렸는지).
5. **낮:** 토론 타이머(기본 3분, +30초) → [투표하기] → "셋, 둘, 하나" 음성에 맞춰 동시에 지목 → 가장 많이 지목된 사람을 눌러 처형합니다. 최후의 변론 30초와 동점·부결도 있습니다.
6. **결과:** 마피아가 모두 죽으면 시민 승리, 마피아 수가 나머지와 같아지면 마피아 승리입니다. 모든 사람의 정체가 공개됩니다.
- 잘못 누른 경우 낮 화면의 **✏️ 생존자 수정**으로 고칠 수 있습니다.
- 앱을 나갔다 와도 **▶ 진행 중이던 게임 이어서**로 계속할 수 있습니다.

## 🤥 라이어 게임 (사회자 진행)
마피아처럼 진행 폰은 TV에, 제시어는 **각자 폰**으로 확인합니다.
1. **준비:** 참가자 이름(사회자 제외), 라이어 수(1명 또는 2명), 모드, 카테고리를 고릅니다.
   - **일반 모드:** 라이어는 카테고리만 알고 제시어를 모릅니다.
   - **바보 모드:** 라이어는 같은 카테고리의 다른 제시어를 받아서, 자기가 라이어인 줄 모릅니다.
   - 카테고리: 음식, 동물, 장소, 직업, 영화·드라마, 스포츠, 물건, 연예인 중 고정하거나 "라운드마다 랜덤"(겹치지 않게 돌아가며 나옴)
2. **접속:** TV의 QR을 **한 번만** 찍으면 됩니다.
   - **📡 노트북 서버**(서버를 켰을 때 기본): 이름은 먼저 고른 사람만 쓸 수 있고, 라운드가 바뀌면 **폰의 제시어가 자동으로 바뀝니다.** 결과가 나오면 폰에도 정답과 라이어가 공개됩니다.
   - **📱 QR만 (서버 없이):** 라운드가 바뀌면 폰에서 [다음 ▶]을 누르고, TV의 라운드 번호와 같은지 확인합니다. 다른 사람 이름을 누르면 그 사람 제시어가 보이니 "본인 이름만"이라고 말해 주세요.
3. **설명:** TV에 카테고리와 **설명 순서**가 뜹니다. 순서대로 한 마디씩 제시어를 설명합니다.
4. **토론 → 투표:** 2분 토론 후 "셋, 둘, 하나"에 동시에 지목하고, 가장 많이 지목된 사람을 누릅니다.
5. **판정:** 라이어를 맞히면 라이어에게 **제시어 맞히기 기회**를 줍니다(일반 모드). 맞히면 라이어 승, 못 맞히면 시민 승. 엉뚱한 사람을 지목하면 라이어 승입니다.
6. 결과 화면에 제시어와 라이어가 공개되고, 누적 전적(시민 n승 · 라이어 m승)이 쌓입니다.

## 📡 노트북 서버 (폰으로 참여하기)
노트북에서 서버를 켜고 노트북을 TV에 연결하면, 참가자들이 **각자 폰으로** 게임에 참여합니다. 서버 없이 열면(미러링 방식) 모든 게임이 예전 방식 그대로 동작합니다.

| 게임 | 서버가 있으면 |
|---|---|
| 🕵️ 마피아 | 이름 잠금, 밤에 손짓 대신 **각자 폰으로 대상 선택**, 경찰 결과는 경찰 폰에만 |
| 🤥 라이어 | 이름 잠금, 라운드가 바뀌면 **폰의 제시어가 자동으로 바뀜** |
| 🎵🎬🔤📸 노래·OST·초성·사진 퀴즈 | **폰 버저**: 먼저 누른 팀이 TV에 뜨고 노래·타이머가 멈춤 |
| 🏅 점수 | 참가자 폰에 팀 점수·개인 순위, 🎤 사회자 폰으로 정답지 보면서 점수 주기 |

### 서버 켜기 (폰 핫스팟 방식)
진행자 폰의 Wi-Fi 핫스팟 하나에 **노트북과 팀원 폰을 모두** 연결합니다. 노트북은 이 핫스팟으로 인터넷(YouTube)을 쓰고, 팀원 폰은 같은 핫스팟 안에서 노트북 서버에 들어옵니다.
```
[진행자 폰] Wi-Fi 핫스팟 ─┬─ 노트북 (서버 + HDMI로 TV)
                          ├─ 팀원 폰 1
                          └─ 팀원 폰 2 …
```
> ⚠️ 각자 LTE/5G 데이터로는 노트북에 들어올 수 없습니다. 반드시 **같은 핫스팟 Wi-Fi**에 연결해야 합니다.

**출발 전 (집에서 한 번)**
1. [Node.js](https://nodejs.org) LTS를 설치합니다 (외부 패키지는 필요 없습니다).
2. 핫스팟을 켤 폰의 **최대 접속 기기 수**를 확인합니다. 노트북 1대 + 팀원 폰 수가 들어가야 합니다(안드로이드 권장).
3. 노트북을 핫스팟에 연결하고 **`start.bat`를 더블클릭**합니다. 서버가 켜지고 브라우저가 `http://localhost:8000`으로 열립니다.
   - 처음 실행할 때 Windows 방화벽 창이 뜨면 **개인·공용 둘 다 체크하고 허용**합니다. 핫스팟은 보통 "공용"으로 잡힙니다.
   - 서버 창(검은 창)은 게임이 끝날 때까지 닫지 마세요. 끄려면 그 창에서 `Ctrl + C`를 누릅니다.
4. ⚙️ 설정의 **📶 핫스팟 Wi-Fi**에 핫스팟 이름과 비밀번호를 넣고 저장합니다. 접속 화면에 **① Wi-Fi QR → ② 게임 QR**이 나란히 떠서, 팀원은 카메라로 두 번 찍기만 하면 됩니다.
5. 폰 2~3대로 **① Wi-Fi QR → ② 게임 QR** 순서로 접속해 보는 리허설을 합니다.

**현장에서**
1. 진행자 폰의 핫스팟을 켜고 **충전기에 연결**합니다.
2. 노트북을 핫스팟에 연결하고, 충전기를 꽂고, 절전과 화면 꺼짐을 끕니다.
3. 노트북을 TV에 HDMI로 연결(`Win + P` → 복제)하고 `start.bat`를 실행합니다. 브라우저에서 `F11`로 전체화면을 켭니다.
4. 홈 → **📱 폰 연결**을 열고 팀원들이 ① Wi-Fi QR, ② 게임 QR을 차례로 찍게 합니다.

**폰이 안 들어올 때**
- 그 폰이 정말 핫스팟 Wi-Fi에 붙어 있는지 확인합니다. "인터넷 없음" 경고 때문에 데이터로 돌아간 경우가 많습니다.
- 접속 화면의 **🌐 다른 주소로 바꾸기**를 눌러 봅니다. 노트북에 네트워크가 여러 개 잡혀 있으면 QR 주소가 엉뚱한 쪽일 수 있습니다.
- 서버를 켠 뒤에 노트북 Wi-Fi를 바꿨다면 서버 창에서 `Ctrl + C`로 끄고 `start.bat`를 다시 실행합니다.
- 끝내 안 되면 서버 없이 진행 폰 미러링 방식으로 바꿔도 모든 게임이 돌아갑니다.
- 포트를 바꾸려면 `PORT=8080 node server.js`처럼 실행합니다.

### 🕵️ 마피아
1. 준비 화면에서 **📡 노트북 서버**를 고르고 역할을 배정합니다.
2. TV에 QR과 주소가 뜹니다. 각자 찍고 자기 이름을 누릅니다. **먼저 고른 사람이 그 이름을 잠그므로** 남의 역할을 볼 수 없습니다. 진행 화면에는 ✅ 접속 중 · 🟡 화면 꺼짐 · ⬜ 아직이 표시됩니다.
   - 폰이 안 들어오면 **🌐 다른 주소로 바꾸기**를 눌러 보세요 (노트북에 네트워크가 여러 개일 때).
   - 이름을 잘못 골랐으면 진행 화면에서 그 이름을 눌러 잠금을 풉니다.
3. **밤:** 생존자 **전원이 동시에** 폰으로 고릅니다. 시민도 "의심 가는 사람"을 골라서, 누가 폰을 두드리는지로 역할이 드러나지 않습니다.
   - 🔪 마피아: 제거할 사람을 고릅니다. 마피아가 2명 이상이면 동료가 고른 사람이 보이고, **모두 같은 사람을 골라야 확정**됩니다.
   - 💉 의사: 지킬 사람을 고릅니다 (자기 자신도 가능).
   - 🚓 경찰: 조사할 사람을 고르면 **결과가 경찰 폰에만** 뜹니다. 조사 기록은 역할 카드 안에 쌓입니다.
   - 진행 화면에는 "4 / 6명 선택 완료"처럼 **숫자만** 나옵니다. 다 고르면 [☀️ 아침으로]를 누릅니다.
   - 끝까지 안 고르는 사람이 있으면 [⏩ 기다리지 않고 진행]을 누릅니다 (마피아끼리 고른 사람이 다르면 아무도 당하지 않습니다). 서버가 말썽이면 [✋ 손짓 방식으로]로 그 밤을 기존 방식으로 진행할 수 있습니다.
4. 낮 토론·투표는 기존과 같습니다. 탈락한 사람의 폰에는 "관전" 안내가 뜨고, 게임이 끝나면 모든 폰에 전체 역할이 공개됩니다.
- 게임 도중 폰이 바뀌거나 접속이 꼬이면 낮 화면의 **📱 접속 관리**에서 확인하고 잠금을 풀 수 있습니다.
- 폰 화면이 꺼졌다 켜지면 자동으로 다시 연결됩니다. 서버를 껐다 켜면 진행 화면은 이어서 할 수 있지만, 참가자는 이름을 다시 골라야 합니다.

### 🤥 라이어
준비 화면에서 **📡 노트북 서버**를 고르면 됩니다 (서버가 켜져 있으면 기본). 접속 화면은 마피아와 같고, 게임 도중에도 라운드 화면의 **📱 접속 관리**에서 접속 상태를 보고 잠금을 풀 수 있습니다.

### 📱 폰 연결: 버저 · 점수 확인
1. 홈 화면의 **📱 폰 연결**을 누르면 QR이 뜹니다. 참가자는 한 번만 찍고 **이름과 팀**을 고르면 행사 내내 그대로 씁니다.
   - **🎲 팀 나누기**를 먼저 하면 그 결과대로 이름만 고르면 됩니다. 명단에 없으면 이름을 직접 적고 팀을 고릅니다.
   - 오른쪽 아래 **📱 n명** 배지로 접속 인원을 볼 수 있고, 누르면 폰 연결 화면으로 갑니다. 이름을 누르면 접속을 끊을 수 있습니다.
2. 게임을 열면 참가자 폰 화면이 자동으로 바뀝니다. 폰이 하나도 연결되지 않았으면 예전 방식으로 진행됩니다.
   - **🔔 버저 (노래·OST·초성·사진):** 폰의 큰 버튼을 먼저 누른 사람이 TV 위쪽에 "🔔 A팀 · 철수"로 뜨고, 노래(또는 10초 타이머)가 멈춥니다. 틀리면 **[❌ 오답 → B팀 기회]**(그 팀은 이번 문제에서 제외), 다시 모두에게 열려면 **[🔁 다시 열기]**를 누릅니다. 정답 처리·다음 문제로 넘어가면 자동으로 다시 열립니다.

## 문제 바꾸기
`js/data.js` 한 파일에 모든 문제가 들어 있습니다.
- **노래**: YouTube 영상 ID만 바꾸면 됩니다 (`youtube.com/watch?v=` 뒤의 11자리). `start`로 시작 초를 지정할 수 있습니다.
- **사진**: `img/` 폴더에 사진을 넣고 `CELEBS`에 추가합니다. `fx`, `fy`는 확대 중심이 될 얼굴 위치(%)입니다.
- **몸으로 말해요 제시어(`CHARADES`), 초성 문제, 라이어 제시어, 벌칙**: 목록에 단어를 추가하거나 빼면 됩니다.
